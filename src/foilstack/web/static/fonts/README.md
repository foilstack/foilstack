# JetBrains Mono

These `.woff2` files are subsets of [JetBrains
Mono](https://github.com/JetBrains/JetBrainsMono), copyright 2020 The JetBrains
Mono Project Authors, licensed under the SIL Open Font License 1.1. The full
licence is in `OFL.txt` beside them, which the OFL requires to travel with the
font — this project redistributes the files, so it carries the licence.

Self-hosted rather than linked from Google Fonts on purpose. A tool whose pitch
is that your scans never leave the machine should not make every page view a
request to a third party, and it has to render the same on a box with no route
to the internet.

Subsets are unicode-ranged, so a latin-only page fetches one 31 KB file rather
than all six.
